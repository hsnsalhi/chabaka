## Format observé (à modéliser)

**Grille rectangulaire** RTL, taille variable (~13×16 typique).

**3 types de cellules** :

1. **Cellule-définition** (fond gris) — contient :
   - Du texte (indice court ou phrase complète)
   - Une **flèche** indiquant le sens de la solution :
     - `→` (en RTL = vers la gauche dans le rendu) = horizontal
     - `↓` = vertical
   - **Cellule double** : peut contenir 2 indices empilés séparés par un trait → 2 mots solutions partant de la même case (un horizontal, un vertical).

2. **Cellule lettre vide** — à remplir avec **une lettre arabe** par case.

3. **Pas de cellule noire** au sens des mots croisés français — les cellules-définitions tiennent ce rôle bloquant.

## Exemples d'indices (grille 72, arabe→arabe)

- `غليظ القلب` (4 lettres) — *insensible*
- `قلب الصفحة` — anagramme/lecture inversée d'un mot
- `قبيلة عربية` — nom de tribu
- `التعامل معها يتطلب بعض الكفاءات الرياضية` — indice long sur plusieurs lignes

## Variante bilingue (grille 11, fr→ar)

- `Doux`, `Sommet`, `Vente`, `Tension`, `Maladie`, `La Fatigue`, `Dévastation`...
- L'utilisateur écrit la traduction arabe.
