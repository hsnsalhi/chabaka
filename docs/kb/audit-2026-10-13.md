## Douteux conservés (à trancher)

- تعبان : Forme familière (égyptien/levantin) ; la forme fusha usuelle est تعِب / متعَب
- صح : Comme adjectif c'est un usage familier ; en fusha صحّ est un verbe, l'adjectif est صحيح
- مبسوط : Au sens « content » c'est un emploi dialectal (darija/égyptien) ; en fusha مبسوط = étendu, large (مبسوط اليد) (proposition : منبسط | كريم اليد)
- ناشف : Usage essentiellement dialectal pour « sec » ; préférer جاف / يابس déjà présents
- أخطبوط دامبو : Nom vernaculaire anglais (Dumbo) transcrit ; très marginal pour un dictionnaire de mots fléchés
- أرغالي : Transcription de argali, rare en arabe ; préférer كبش بري / وعل
- أوسيلوت : Transcription de ocelot, peu attestée en arabe
- إكثيوصور : Transcription de ichthyosaure, très rare en arabe
- بايثون : Transcription de python ; le terme arabe est الأصلة (ou البيثون)
- بتروداكتيل : Transcription de ptérodactyle, rare en arabe
- تيس الأنديز : Animal non identifiable ; semble inventé (confusion avec lama/alpaga ?)
- جاغوار : Doublon de transcription avec جاكوار (5464) ; le mot arabe est يغور
- خروف بلدي : Expression de langage courant (بلدي = local), pas une entrée lexicale
- سمك الديسك : ديسك est une transcription (discus) non établie ; préférer سمكة القرص (proposition : سمكة القرص)
- سيليكانث : Transcription de cœlacanthe, très rare en arabe (شوكيات الجوف)
- فلامينغو : Doublon orthographique de فلامنغو (10586) ; le mot fusha est النحام
- فيلوسيرابتور : Transcription de vélociraptor ; marginal
- كاكاتو : Doublon de transcription avec كوكاتو (11692)
- كوغار : Transcription de cougar ; en arabe أسد الجبل / البوما
- نسر أبيض : Espèce non identifiable, doublon approximatif de نسر أصلع (14113)
- إيواني : Adjectif relatif très rare ; l'indice رواق مفتوح ne lui correspond pas
- بنجو : Doublon de بانجو (3828) ; بنجو désigne plutôt le bingo

- ساكسفون : Doublon orthographique de ساكسوفون (7869)

- الأورطى : Transcription médicale (aorte) ; graphie usuelle الأورطي, et le terme fusha الأبهر est déjà l'indice (proposition : الأورطي)
- تركوازي : Adjectif tiré de la transcription turquoise ; le mot arabe est فيروزي (déjà l'indice)
