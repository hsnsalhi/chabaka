## Erreurs d'API

- `GET /{post_id}/insights?metric=post_impressions,post_impressions_unique,post_engaged_users,post_clicks` → HTTP 400, erreur `(#100) The value must be a valid insights metric` (OAuthException, code 100). Un nouvel essai avec la seule métrique `post_impressions_unique` renvoie la même erreur : ces métriques de post ne sont plus acceptées par la v26.0 de l'API (il ne s'agit pas d'un refus de permission).
- `GET /{page_id}/insights?metric=page_impressions,page_post_engagements&period=day` → HTTP 400, même erreur `(#100) The value must be a valid insights metric`.
- Les quatre autres requêtes (post, commentaires, page) ont répondu HTTP 200.

À faire côté outillage : vérifier dans la documentation des Page Insights de la v26.0 quelles métriques restent disponibles (par exemple `post_impressions` a pu être retirée au profit d'autres noms), ou passer par `/{post_id}?fields=insights.metric(...)` si la forme change ; en attendant, impressions et portée ne sont pas relevées.
